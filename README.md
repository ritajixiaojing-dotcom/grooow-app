## ✨ 核心亮点

- 🔒 **隐私安全**：API Key 仅加密保存在用户浏览器本地（`localStorage`），绝不上传服务器或代码仓库，永不泄露。
- ⚡ **最新 AI 引擎**：支持 Gemini 2.0 Flash / Gemini 1.5 Flash / Gemini 1.5 Pro。
- 🎯 **爆款结构化输出**：
  - 3~5 个高点击率爆款备选标题（支持单独一键复制）
  - 网感排版正文（Emoji 巧妙穿插、空行留白、分段呼吸感）
  - 热门话题标签推荐（Tags）
- 📸 **图片/相机多模态识别**：支持拍照或相册选图，AI 深度识别画面主体与氛围感融入文案。
- 🎭 **场景与风格定制**：
  - 场景：种草安利、探店打卡、干货教程、避坑指南、日常记录、穿搭美妆、搞钱职场
  - 语气：热情闺蜜、资深博主、幽默逗趣、高级极简、震惊测评
  - Emoji 密度调节：网感爆棚、适度点缀、简约清爽
- 📱 **PWA 手机桌面独立 App**：可直接添加到 iPhone / Android 手机桌面，无需下载 App 即可享受原生般全屏体验。
- 🕒 **历史记录**：本地自动保存历史文案，随时回溯与复制。

## 📲 如何安装到手机桌面 (iPhone / Android)

### 🍎 苹果 iPhone / iPad
1. 用自带 **Safari 浏览器** 打开网站：`https://ritajixiaojing-dotcom.github.io/grooow-app/`
2. 点击屏幕底部的 **分享按钮**（带箭头的方框图标 ⎋）
3. 向上滑动菜单，点击 **「添加到主屏幕」➕**
4. 点击右上角「添加」，手机桌面上就会出现 **grooow** 专属 App 图标！

### 🤖 安卓 Android (Chrome / 华为 / 小米等浏览器)
1. 用 **Chrome 浏览器** 打开网站
2. 点击右上角菜单按钮（三个点 ⋮）
3. 点击 **「添加到主屏幕」** 或 **「安装应用」** 即可。

## 🔑 首次配置 API Key

1. 访问 [Google AI Studio](https://aistudio.google.com/app/apikey) 免费申请一个 Gemini API Key。
2. 打开本网站，点击右上角 **「设置」⚙️**。
3. 粘贴您的 API Key 并点击保存即可开始使用。
